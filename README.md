# Посмотри в окно

Проектная работа Яндекс Практикума. Приложение показывает видео из разных городов и позволяет фильтровать их по названию города и времени суток.

## Запуск

Откройте `index.html` в браузере. Для загрузки карточек и видео нужен доступ к `v-content.practicum-team.ru`.

[Репозиторий на GitHub](https://github.com/matthew1200/posmotri-v-okno-ad)
